命式を読む

1990年5月15日 10:00 生 ／ 日主 庚 — 用語を押すと注釈が浮きます

五行バランス

強み

5軸のうち、いちばん高く出ているのはで、値は 4.8（外周 5）です。全軸の平均が 2.4 ですから、平均より 2.4 高く、外周までの 96％ まで届いている計算になります。ここまで一点に力が集まると、命式の輪郭はこの軸で決まります。初対面でも伝わるほど持ち味がはっきり出る反面、調子の良し悪しがそのまま生活の波になりやすく、この軸が空回りしたときの立て直しには時間がかかります。の中でこの気が濃いということは、体の使い方も物の考え方もその色に寄るということです。いちばん低い（0.3）との開きは 4.5。この落差が、そのままあなたの輪郭になっています。
