UI モック 10 案

2026 年の UI 潮流を調べ、100 案を出して 10 案に絞ったもの。データは実 API の実測値（1990-05-15 10:00 生・日主 庚）を使っています。選定の経緯と落とした案は README.md に。

01

Bento ダッシュボード

10 枚のチャートを粒度の違うカードに再編。カードを押すとその場で展開し、画面遷移なしで掘れます。

Bento 2.0ドリルダウンFLIP アニメ
02

夜のガラス

すりガラスを全面ではなく、浮いている要素（ドック・注釈）にだけ効かせる Glassmorphism 2.0 の作法。

Glass 2.0ダーク用語ポップオーバー
03

スクロールで組み上がる命式

四本の柱を一本ずつ立てていく読み物。上部の盤がスクロールに同期して埋まります。

目的のあるモーションstickyスクロール同期
04

五行の相生相剋ダイアグラム

円の大きさが強さ、線が関係。丸を選ぶと、生む先・剋す先が光ります。この題材にしかない図。

関係の可視化ノード選択
05

Calm リーディング

装飾を捨てて読み物に振り切った版。要約 1 行 → 本文 300 字の 2 段構えで、開いた人だけが深く読めます。

Calm / low-stimulus明朝漸進的開示
06

相性スワイプ

カードを持ち上げるほど、背面の相性の根拠が透けて見える。判断材料を出しながら送れます。

ジェスチャードラッグキーボード対応
07

会話型オンボーディング

1 問ずつ、なぜ聞くのかを添えて。答えるたびに命式のプレビューが育ちます。「分からない」も一級の選択肢。

会話型 UI逐次入力ライブプレビュー
08

二人のレーダー比較

二人分を重ね、差分をハッチで塗る。スライダーで軸を送ると、その軸の差だけを読めます。

2 系列CVD 検証済み配色スクラブ
09

十二支の回転盤

盤をドラッグして回し、上に来た支を選ぶ。六合と冲が線で結ばれ、自分の支は濃く表示されます。

円環メタファ回転ドラッグスナップ
10

根拠を開く説明パネル

点数だけを出さず「この 84.9 はどこから来た？」を開ける。実際の計算をそのまま辿ります。

AI は副操縦士説明レイヤドロワー
すべて単体で動く静的 HTML（外部依存なし・ビルド不要）。
prefers-color-scheme と prefers-reduced-motion を各モックで尊重しています。
