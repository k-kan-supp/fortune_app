五つの勢力のうち比劫が大きいのは、命式の力の使い道が「自分の強さと仲間との関係」に決まっているということです。人生の選択でも自然とこの勢力に沿った道を選びやすく、逆らった選び方をすると疲れが早く出ます。

この命式のひとこと

詳しく

金と比劫に力が集まった、輪郭のはっきりした命式。押す力は強く、広げる力は控えめ。

金 4.8・比劫 4.8 と、五行と勢力の両方で一点集中の形が出ています。実行力（57.1）が高く表現力（11.8）が低いのは同じ偏りの裏表で、決めて動くことは得意でも、それを外に説明する回路は薄いということです。表現を担う食傷が 0.3 しかない点が、そのまま恋愛運 10.2 の低さにもつながっています。
