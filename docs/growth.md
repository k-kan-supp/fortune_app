# 集客戦略（50視点）

マネタイズ側は [monetization.md](monetization.md)。この2本で「100視点」の整理になっている。

このプロダクトには集客上の強みが2つある。
**(a) 命式の計算そのものが検索需要のある無料ツール**であること、
**(b) 相性判定に相手の生年月日が要る＝人を誘う理由が機能に内蔵されている**こと。
広告を買う前に、この2つを絞り切る。

## 1. 検索（1–10）

| # | 視点 | 中身 |
| --- | --- | --- |
| 1 | 主要キーワード | 「四柱推命 無料」で命式計算 |
| 2 | ツール型ページ | 入力→結果を1画面で完結 |
| 3 | 用語辞典 | [saju-glossary.md](saju-glossary.md) を全語ページ化 |
| 4 | 日付別 | 生年月日ごとの静的ページ |
| 5 | 干支別 | 60通りの解説記事 |
| 6 | 十神別 | 10種の解説記事 |
| 7 | 内部リンク | 用語↔結果画面を相互に張る |
| 8 | 構造化データ | FAQ / HowTo |
| 9 | 表示速度 | 初回表示を軽く保つ |
| 10 | 多言語 | ja/en 既存＋韓国・台湾 |

3 は既に日本語で書かれた資産があるので、公開ページ化のコストが最も低い。
10 は i18n が既に ja/en 同型で入っている（`frontend/src/i18n/messages/`）ぶん、
新言語の追加が構造的に安い。

## 3. 構造的バイラル（21–25）

| # | 視点 | 中身 |
| --- | --- | --- |
| 21 | 誘う理由 | 相性には相手の生年月日が要る |
| 22 | カップル招待 | 2人で見る前提の画面 |
| 23 | グループ診断 | 友人・家族単位 |
| 24 | 先出し | 登録前に結果を見せる |
| 25 | 会員化の動機 | 「保存したい」瞬間に出す |

ここが最も費用対効果が高い。21 は機能の必然であって施策ではないので、
広告と違って**止めても効き続ける**。24→25 の順序を逆にする（登録を先に要求する）と
入口で大半が落ちるため、登録は結果の後ろに置く。

## 優先順位

1. **1–4** — 命式計算のSEO。無料で出し切る前提（[monetization.md](monetization.md) 1）と表裏。
2. **21・24** — 相性の構造的拡散と、登録前の結果表示。
3. **34** — 計測基盤。これが無いと以降の判断が全部勘になる。

36 以降（買う集客）は 1–35 の数字が出てからで良い。
