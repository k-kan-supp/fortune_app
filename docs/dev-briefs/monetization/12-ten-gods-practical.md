# M12 十神の実践解釈

親: [マネタイズ設計](../../monetization.md) 視点12 ／ 関連: [M16](16-career-reading.md) [M11](11-hidden-stems-detail.md)

## ねらい

`ten_gods.py` が出す十神を「性格の説明」で終わらせず、
**行動の指示**に変換する。「比肩が強い」ではなく「人に任せるより自分で握った方が結果が出る。
ただし共同経営は揉める」まで書く。ここが有料の解釈文の中核で、
無料区画との差が最もはっきり出る面。

## 実装

**backend**

- `app/services/saju/narrative.py` に `ten_gods_practical()` を追加。
  入力は十神の分布と強弱（`analysis.py` の指標を流用）、出力は場面別の `body_code`。
- 場面は対人・恋愛・自己管理の3分類。**仕事は [M16](16-career-reading.md)、
  金銭は [M17](17-wealth-reading.md) が持つ**ので、ここでは扱わない。
  同じ話題を2か所に書くと、読者は同じ内容に二度課金させられたと感じる。
- 強弱は3段階（強い / 標準 / 弱い〜無い）に離散化する。連続値のまま文言を分岐させると
  組み合わせが爆発し、書ける量を超える。10種 × 3場面 × 3段階 = 90 文が上限。
- 「無い」の解釈を必ず書く。十神は欠けている方が読み応えがあり、体験の質を左右する。

**境界**: この指示書は**十神という単一要素**の解釈を持つ。
複数の材料（十神＋大運＋五行）を統合したテーマ別鑑定は M16〜M20 の担当。

**frontend**

- `features/fortune/components/ResultSummary.tsx` に場面タブを追加。
  3分類を全部縦に並べると読まれない。
- ja/en 同時。en は直訳を避け、十神名はローマ字＋意訳の併記にする。

## 検証

- 90 パターン全てにコードが存在すること（欠けをテストで検出）。
- 仕事・金銭に踏み込んだ文言が含まれないこと（M16/M17 との重複検出）。
- 十神が1つも無いケース（極端な命式）で空にならないこと。
- 強弱の閾値を `test_narrative.py` で固定する。閾値が動くと文言が総取っ替えになる。
