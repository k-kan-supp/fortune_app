# M16 適職・転職鑑定

親: [マネタイズ設計](../../monetization.md) 視点16 ／ 関連: [M12](12-ten-gods-practical.md) [M13](13-luck-cycles.md)

## ねらい

テーマ別鑑定の第1弾。適職は**単価を最も上げやすい**題材で、
転職を考えている人は数千円を払う。既存の十神（[M12](12-ten-gods-practical.md)）と
大運（[M13](13-luck-cycles.md)）の組み合わせで作れるので、新規の占術ロジックは要らない。

## 実装

**backend**

- `app/services/saju/readings/career.py` を新設し、テーマ別鑑定の置き場所をここに決める。
  以降 [M17](17-wealth-reading.md)〜[M20](20-naming-reading.md) も同じディレクトリに並べる。
  最初の1本でディレクトリの形を決めきることが、この指示書の裏の目的。
- 入力は命式＋大運、出力は「向く働き方」「向かない環境」「動くべき時期」の3節。
  職種名を断定しない。「営業に向く」は外れたときの落差が大きく、返金要求に直結する。
  働き方の性質（裁量の大小、対人量、変化の頻度）で書く。
- 時期は大運・年運から出す。ここが単なる性格診断との差になる。

**frontend**

- 独立ページではなく `ResultPage.tsx` 内のテーマ選択にする。
  ページを増やすと導線が薄まる。
- ja/en 同時。

## 検証

- `backend/tests/services/readings/test_career.py` を新規作成。
- 3節が全て埋まること。大運が未計算のユーザーで落ちないこと。
- 断定的な職種名が出力コードに含まれないこと（コード一覧を走査するテスト）。
