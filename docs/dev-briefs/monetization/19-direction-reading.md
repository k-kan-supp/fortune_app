# M19 方位・引越鑑定

親: [マネタイズ設計](../../monetization.md) 視点19 ／ 関連: [M16](16-career-reading.md) [M14](14-lucky-day-calendar.md)

## ねらい

引越・出張・旅行の方位。**買うタイミングが明確**（引越を決めた人）で、
単価も高い。既にプロフィールに都道府県（`i18n/prefectures.ts`）を持っているので、
出発地の入力を省ける点が有利。ただし方位は九星気学の領域で、
四柱推命とは体系が違う。混ぜるなら「別体系である」と明示する。

## 実装

**backend**

- `app/services/saju/readings/direction.py`。
  本命星は生年（立春基準）から求める。四柱の年柱と起点がずれる点に注意。
  **節分・立春をまたぐ生まれの扱い**が最頻出の間違いで、ここだけは既存の節気計算を必ず使う。
- 出力は「動きやすい方位」「避けたい時期」「移動の質」の3節。
  凶方位を断定的に「行くな」と書かない。不安を煽る商品にすると継続しない。
- 出発地は緯度経度ではなく都道府県の粒度に留める。番地単位の精度は占術上も意味が無く、
  位置情報の取り扱いが重くなるだけ。

**frontend**

- 出発地は `features/profile/` の登録値を初期値にし、その場で変更もできるようにする。
- 方位図は8方位の円形表示。既存 `RadarChart.tsx` は流用できないので新規。
- 「四柱推命とは別の体系（九星気学）に基づく」注記を必ず入れる。
- ja/en 同時。en では方位名を方角の英語表記に。

## 検証

- 立春前後の生まれで本命星が正しく切り替わること（境界テスト必須）。
- 全47都道府県で方位が計算できること。
- 年をまたぐ移動計画で年の切り替えが立春基準になっていること。
