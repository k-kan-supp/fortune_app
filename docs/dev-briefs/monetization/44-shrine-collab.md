# M44 神社仏閣コラボ

親: [マネタイズ設計](../../monetization.md) 視点44 ／ 関連: [M19](19-direction-reading.md) [M43](43-merch.md)

## ねらい

方位鑑定（[M19](19-direction-reading.md)）と参拝先の提案を結び付ける。
「あなたの命式なら今年はこの方角の神社」は自然な組み合わせで、
コラボ先にとっても参拝者の送客になる。**宗教施設が相手なので、
占いと信仰を混同した表現をしない**配慮が要る。実装より関係構築が本体。

## 実装

**backend**

- `app/services/commerce/partners.py` に提携先データ（名称・所在地・方位・受け入れ可否）。
  所在地は都道府県＋市区町村の粒度。[M19](19-direction-reading.md) の方位計算と同じ粒度に揃える。
- 提携先の掲載可否・掲載文言は**先方の承認したテキストをそのまま使う**。
  自動生成した紹介文を出さない。宗教施設の説明を機械が書くのは事故のもと。
  データに `approved_text` を持ち、それ以外を表示しない構造にする。
- 御朱印・授与品の販売はこちらで扱わない。決済を持つと責任範囲が一気に広がる。
  情報掲載と送客に留める。

**frontend**

- 方位鑑定の結果に「この方角の提携先」を添える。
- 「占いに基づく提案であり、宗教的な効能を保証するものではない」旨を明記。
- 提携である旨の表示（[M37](37-affiliate-goods.md) の規律）に従う。
- ja/en 同時。en では神社仏閣の説明に注意（訪問マナーの注記があると親切）。

## 検証

- 承認テキスト以外が表示されないこと（型・テストで担保）。
- 提携解除時に即座に非表示になること。
- 方位計算の結果と掲載される提携先の方角が一致すること。
