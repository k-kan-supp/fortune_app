# M13 大運・年運

親: [マネタイズ設計](../../monetization.md) 視点13 ／ 関連: [M08](08-annual-plan.md) [M14](14-lucky-day-calendar.md)

## ねらい

命式が「変わらないもの」を語るのに対し、大運・年運は**時期**を語る。
「いつ動くべきか」は最も金額を払われやすい問いで、年額プラン
（[M08](08-annual-plan.md)）の中心商品にする。計算は未実装なので、
このシリーズで唯一まとまった新規ロジックが要る。

## 実装

**backend**

- `app/services/saju/luck_cycles.py` を新設。
  - 大運: 月柱を起点に順行/逆行を年干の陰陽と性別で決め、10年ごとに干支を進める。
  - 起運年齢は生誕から次（前）の節入りまでの日数を3で割る。ここが最も間違えやすい。
    節気は既存の `sxtwl` 経由の計算（`calendar` 相当の処理）を再利用し、自前で暦を持たない。
  - 年運: 対象年の年柱を出し、日干との十神関係を求める。
- 出力は既存チャートと同じ形に揃える（`key` / `axes`）と、フロントの表示器が使い回せる。
- `app/schemas/fortune.py` に追加。`app/api/routes/fortune.py` は薄いまま。

**frontend**

- 年表形式で表示する新コンポーネント。既存の `RadarChart.tsx` では時系列が表せない。
- 現在位置（今いる大運）を強調。ここが読者の関心の中心。
- ja/en 同時。

## 検証

- `backend/tests/services/test_luck_cycles.py` を新規作成。
  **順行/逆行と起運年齢**を、既知の生年月日の期待値で固定する。ここが崩れると全部ずれる。
- 節入り直前・直後の生まれで起運年齢が正しく変わること。
- うるう年・年またぎの境界。
