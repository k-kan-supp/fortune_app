# M28 アンカー価格

親: [マネタイズ設計](../../monetization.md) 視点28 ／ 関連: [M27](27-decoy-plan.md) [M06](06-first-free.md)

## ねらい

最初に見せる数字が、その後の価格判断の基準になる。
このプロダクトなら**対面の占い鑑定（1回5,000〜10,000円）**が自然なアンカーで、
それに対して月額980円がどう見えるかを設計する。
ただし架空の「通常価格」を作って割引に見せるのは**二重価格表示**として景品表示法上の問題になる。
実在しない元値は絶対に置かない。

## 実装

**backend**

- 比較の基準になる数字は「自社の上位プラン」か「自社の単発鑑定の実売価格」に限定する。
  `catalog.py` に `compare_at` を置くなら、それは**実際に販売している商品の価格**を参照する形にし、
  自由入力の数値を持てないようにする。型で防ぐ。
- 割引表示は決済プロバイダのクーポンが実在する場合のみ。
  UI 都合の「〇%OFF」文字列を作らない。

**frontend**

- 単発鑑定（[M03](03-one-off-report.md)）の価格を先に見せ、その後に月額を出す。
  「1回分の値段で1ヶ月」が成立する価格設計にしておく。
- 無料枠（[M06](06-first-free.md)）使用後に通常価格を同じ画面に出す。
  体験直後が最もアンカーが効く瞬間。
- ja/en 同時。

## 検証

- `compare_at` に実在しない価格が入らないこと（参照整合をテスト）。
- 割引表示がクーポン実在時のみ出ること。
- 期間限定表記を出す場合、期限が実際に切れること。
