# M47 API 提供

親: [マネタイズ設計](../../monetization.md) 視点47 ／ 関連: [M48](48-white-label.md) [M46](46-b2b-team-fit.md)

## ねらい

`services/saju/` は**フレームワーク非依存の純ロジック**として作られている
（[architecture.md](../../architecture.md)）。この設計がそのまま外販の資産になる。
命式計算・十神・十二運・相性を従量課金の API として出す。
他社のアプリやサイトに組み込まれると、営業せずに使用量が伸びる。

## 実装

**backend**

- `app/api/routes/public/v1/` を新設。**バージョンを最初から切る**。
  外部が使う API は後方互換の制約が一気に厳しくなる。v1 を切らずに出すと後で詰む。
- レスポンスは既存の内部 API と**別のスキーマ**にする。
  内部の都合でフィールドを変えたときに外部が壊れる構造にしない。
  `app/schemas/public/v1.py` を独立させる。
- API キー・レート制限・使用量計測を最初から入れる。後付けは必ず漏れる。
  `app/core/middleware.py` に計測を足す。
- 課金は月次の使用量ベース。無料枠（例: 月1,000リクエスト）を出して試させる。
- OpenAPI ドキュメントは FastAPI の `/docs` をそのまま外部公開せず、
  public ルートだけの別ドキュメントを出す。内部エンドポイントを晒さない。

## 検証

- 内部スキーマを変更しても public v1 の出力が変わらないこと（スキーマ固定テスト）。
- レート制限が効くこと。
- 無効なキーで 401 になること。
- public ドキュメントに内部エンドポイントが含まれないこと。
