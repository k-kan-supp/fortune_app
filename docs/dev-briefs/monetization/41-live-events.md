# M41 オンライン鑑定会

親: [マネタイズ設計](../../monetization.md) 視点41 ／ 関連: [M42](42-community-subscription.md) [M39](39-reader-marketplace.md)

## ねらい

数十人規模のオンライン鑑定会をチケット制で開く。
1対1の個別鑑定より単価あたりの提供コストが低く、
**コミュニティの起点**（[M42](42-community-subscription.md)）にもなる。
配信基盤を自作しない。既存のビデオ会議サービスに寄せる。

## 実装

**backend**

- `app/models/event.py`（開催）と参加チケット。定員管理が要る。マイグレーション必須。
- **定員超過の防止**が実装上の要点。在庫1つを複数人が同時に取りにくるので、
  定員チェックと予約作成を同一トランザクション＋行ロックで行う。
  楽観的にやると必ず超過が出る。
- 配信 URL は開催24時間前まで伏せる。事前に漏れると無料参加される。
  参加者にのみ返す API にし、URL をイベント一覧に含めない。
- キャンセル期限と返金規定を先に決めて実装する。運用で判断しない。
- 参加者の命式を事前に集めるなら、**何に使うかを明示して同意を取る**。
  当日の題材にする場合は、匿名化して扱うか本人の許可を個別に取る。

**frontend**

- 開催一覧・申込・当日の入室導線。
- 定員残数をリアルタイムに近い形で表示。売り切れ表示が遅れると苦情になる。
- ja/en 同時。開催が日本語のみなら en 側で明示する。

## 検証

- 同時申込での定員超過が起きないこと（並行テスト）。
- 未申込ユーザーが配信 URL を取得できないこと。
- キャンセル期限前後の返金判定。
