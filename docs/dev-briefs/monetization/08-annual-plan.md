# M08 年額プラン

親: [マネタイズ設計](../../monetization.md) 視点8 ／ 関連: [M26](26-three-tier-pricing.md) [M13](13-luck-cycles.md)

## ねらい

四柱推命は**年運・大運という年単位の商品**を持っているので、年額は理屈が通る。
「今年一年の流れ」を年額特典にすると、月額との差が値引きではなく中身の差になり、
値引き合戦にならずに単価が上がる。

## 実装

**backend**

- `subscription.plan` に `daily_yearly` を追加。判定は `entitlement.py`
  （[M05](05-hybrid-billing.md)）に集約したまま、プラン名の分岐をそこだけに置く。
- 年額のみ `services/saju/` の年運出力（[M13](13-luck-cycles.md)）を開放する。
  service 側は「年運を計算する」だけで、誰が見られるかは知らない。
- 月額→年額の切り替え時は残期間を按分して繰り越す。切り捨てるとサポート対応が発生する。
- 解約は期間末まで有効。即時停止にしない。

**frontend**

- 価格は月換算で併記（例: 年額 9,800 円 / 月あたり 816 円）。
  年額の総額だけを出すと高く見えて選ばれない。
- 年額の推し時は加入直後ではなく**2ヶ月目**。初月から年額を強く出すと月額の入口を潰す。
- ja/en 同時。en 側は通貨表記の扱いを揃える。

## 検証

- 月額→年額の按分計算をテストで固定（端数の丸め方向まで）。
- 年額加入者に年運が出て、月額加入者に出ないこと。
- 解約後、期間末までアクセスできること。
