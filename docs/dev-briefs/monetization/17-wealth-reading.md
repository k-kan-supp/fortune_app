# M17 金運鑑定

親: [マネタイズ設計](../../monetization.md) 視点17 ／ 関連: [M16](16-career-reading.md) [M13](13-luck-cycles.md)

## ねらい

テーマ別鑑定の第2弾。金運は検索需要が大きく単価も高いが、
**最も炎上しやすい題材**でもある。投資判断や具体的な金額の助言と受け取られる書き方をすると、
金融商品取引法まわりの問題になる。ここは占いの範囲に留める設計を先に固める。

## 実装

**backend**

- `app/services/saju/readings/wealth.py`（[M16](16-career-reading.md) の構成に従う）。
- 材料は正財・偏財の十神、財星の強弱、大運の財の巡り。
- 出力は「稼ぎ方の型」「貯まりにくい理由」「出費が動く時期」の3節。
  **禁止事項を実装レベルで固定する**: 銘柄・投資商品・具体的金額・利回りに言及するコードを作らない。
  文言テーブルに対する禁止語チェックをテストで回す。
- 「時期」は断定を避け、傾向として書く。

**frontend**

- 画面下部に「これは占いであり、投資判断・財務助言ではありません」を常時表示。
  モーダルの同意ではなく常時表示にする。読まれない同意は意味が無い。
- ja/en 同時。免責文言は `core/i18n.py` ではなくフロントの i18n に置く（表示専用のため）。

## 検証

- 禁止語（銘柄名、「必ず儲かる」「投資すべき」等）が文言に含まれないことをテストで検出。
  語彙リストはテスト側に置き、文言追加時に自動で引っかかるようにする。
- 3節が全て埋まること。
