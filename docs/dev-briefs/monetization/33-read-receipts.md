# M33 既読・足あと解放

親: [マネタイズ設計](../../monetization.md) 視点33 ／ 関連: [M34](34-premium-filters.md) [M32](32-like-packs.md)

## ねらい

「誰が自分を見たか」「メッセージが読まれたか」を有料で開放する。
不安を材料にする課金なので、**設計を誤ると体験を悪化させる**。
情報を隠して不安を作り、その不安を売る構造にしない。
既定を「見られていない側にも配慮する」側に置くことが条件。

## 実装

**backend**

- `app/models/matching.py` に閲覧記録（`viewer_id` / `viewed_id` / `viewed_at`）を追加。
  保持期間を30日にして自動削除する。永続の足あと台帳は作らない。マイグレーション必須。
- **相互性の原則**: 足あとを見る側は、自分の足あとも相手に見せる設定にする。
  片方向の監視構造を作らない。ここは実装で担保する（設定で片方向にできないようにする）。
- 既読は送信者・受信者の双方が同じ条件で見えるようにする。
  課金者だけが既読を見られる設計は、無課金側にとって一方的に不利。
  課金で開放するのは**足あと一覧**に留め、既読は全員に出す方が健全。
- `ChatWindow.tsx` 側の既読 API は無料のまま。

**frontend**

- 足あとを非表示にする設定を無料で提供する。
  見られたくない人の逃げ道が無い機能は使われない。
- ja/en 同時。

## 検証

- 30日経過した閲覧記録が消えること。
- 足あと非表示設定時、課金者からも見えないこと。
- ブロック済み（`BlockedPage.tsx` の対象）ユーザー間で記録が残らないこと。
