# M29 ペイウォール位置

親: [マネタイズ設計](../../monetization.md) 視点29 ／ 関連: [M01](01-free-paid-line.md) [G33](../growth/33-ab-testing.md)

## ねらい

**Mシリーズで最も転換率を動かす1本**。同じ商品・同じ価格でも、
壁をどこに置くかで数倍変わる。原則は「最も刺さる一文の直前」。
命式を見て「当たっている」と感じた直後に壁が来るのが最も効く。
逆に、まだ何も読んでいない段階で壁を出すと、価値が伝わる前に離脱する。

## 実装

**backend**

- 壁の位置を**設定として持つ**。無料/有料の帰属は
  [M01](01-free-paid-line.md) が決めるので、ここで決めるのは
  **有料区画の何ブロックを予告として見せるか**（プレビュー量）。
  `narrative.py` のブロック列に対してサーバ設定で変えられるようにする。
  コードに埋め込むと検証のたびにデプロイが要る。
- ブロックには `hook_strength`（引きの強さ）を持たせ、
  強いブロックの**直前**で切れるよう自動調整する。固定インデックスで切ると、
  命式によって「つまらない所で切れる」ことが起きる。
- 切断位置は [G34](../growth/34-analytics-foundation.md) のイベントに含めて記録する。
  記録が無いと [G33](../growth/33-ab-testing.md) で比較できない。

**frontend**

- `ResultSummary.tsx` の壁は「続きがある」ことを視覚的に示す。
  ぷつりと終わるのではなく、次の見出しは見せて本文をぼかす。
- 壁の下に何本残っているかを数で示す（「あと7項目」）。量の提示は強い。
- ja/en 同時。

## 検証

- 設定変更だけで壁の位置が動くこと（デプロイ不要）。
- どの位置でも無料区画だけで意味が通ること。文の途中で切れないこと。
- 有料本文がレスポンスに含まれないこと（[M01](01-free-paid-line.md) と同じ検査）。
