# G15 TikTok ショート

親: [集客戦略](../../growth.md) 視点15 ／ 関連: [G16](16-youtube-readings.md) [G19](19-influencer-program.md)

## ねらい

占いは短尺動画で最も伸びるジャンルの1つ。
ただし**これは開発タスクではなく制作タスク**で、
エンジニアリングでできることは限られている。
指示書としての価値は「開発側が何を用意すべきか」を切り分けることにある。

## 開発側が用意するもの

- **動画に映せる画面**を作る。命式が出るまでの30秒が絵になるかどうかが全て。
  入力→結果の遷移に、間の持つアニメーションがあると撮影しやすい。
  無音で見ても何が起きているか分かること。
- 縦画面（9:16）で見栄えするレイアウト。既存のレスポンシブ対応が
  縦長の極端な比率で崩れないことを確認する。
- 撮影用に、任意の生年月日を素早く入力できる状態にしておく。
  デモ用のプリセットがあると制作が速い。開発用のクエリパラメータで十分。
- 動画からの流入を計測できるようにする（[G34](34-analytics-foundation.md) の
  流入元パラメータ）。TikTok からの流入は計測が弱いので、
  専用のランディング URL を用意する。

## 開発側がやらないこと

- 動画の自動生成。品質が伴わず、プラットフォーム側の評価も低い。
- 投稿の自動化。この規模では手動で足りる。

## 検証

- 縦画面（9:16 相当の狭い幅）でレイアウトが崩れないこと。
- 専用ランディングからの流入が計測できること。
- 結果表示までのアニメーションが無音で理解できること。

## 完了条件

- [ ] 縦画面で崩れない
- [ ] 流入計測ができる
- [ ] デモ用の入力プリセットがある
- [ ] `check.sh` 緑
