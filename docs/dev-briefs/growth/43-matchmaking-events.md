# G43 婚活イベント提携

親: [集客戦略](../../growth.md) 視点43 ／ 関連: [G44](44-marriage-agencies.md) [G23](23-group-reading.md)

## ねらい

婚活イベントの参加者に、その場で相性診断を提供する。
**イベントは「話すきっかけ」を必要としている**ので、
相性診断はコンテンツとして歓迎されやすい。
主催者にとっては場が盛り上がり、こちらは購入意欲の高い層をまとめて獲得できる。

## 実装

**開発側**

- **イベント用の一括入力**が要る。参加者20〜30人の生年月日を
  主催者が一度に投入し、全ペアの相性を出す。
  [G23](23-group-reading.md) の N 者拡張を流用するが、
  人数上限（8人）を超えるので、イベント用の別経路にする。
- 出力は「話が合いそうな相手上位3人」を各参加者に渡す形。
  **全ペアのスコア表を主催者に渡さない**。誰と誰が最低点かが可視化されると、
  イベントの場が壊れる。[G23](23-group-reading.md) と同じ規律。
- 参加者データはイベント終了後に自動削除する（例: 7日）。
  婚活参加者の名簿を保持しない。ここは明確に線を引く。
- 参加者本人の同意を主催者経由ではなく**本人から**取る。
  主催者が代理で同意する構造にしない。

**現場対応**

- オフラインでも動く形（事前に生成して印刷、[M24](../monetization/24-pdf-export.md)）を用意する。
  会場の回線は当てにならない。

## 検証

- 30人規模の一括計算が現実的な時間で終わること。
- 全ペアのスコア表が出力されないこと。
- 保持期限後にデータが消えること。
- 本人同意なしの参加者が計算対象にならないこと。
