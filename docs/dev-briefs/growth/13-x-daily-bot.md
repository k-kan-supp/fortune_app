# G13 X 定時投稿

親: [集客戦略](../../growth.md) 視点13 ／ 関連: [G30](30-solar-term-alerts.md) [M14](../monetization/14-lucky-day-calendar.md)

## ねらい

`daily.py` は毎日必ず新しい内容を生成する。
**投稿ネタが自動で尽きない**のが四柱推命アプリの構造的な強みで、
毎朝の定時投稿を運用コストほぼゼロで続けられる。
「今日は〇〇の日」は反応が取りやすく、フォロワーの積み上げに向く。

## 実装

**backend**

- `app/services/social/publisher.py` を新設。投稿内容の生成と送信を分ける。
  生成部分はテスト可能な純関数にし、送信は差し替え可能にする。
- 投稿内容は「今日の日干支」＋「四領域のうち最も動く領域」＋固定リンク。
  個人の命式に依存しない**その日全体の傾向**にする。個人向けは通知（[G26](26-push-timing.md)）の役目。
- 画像を付ける（[G11](11-share-card-image.md) の基盤を再利用）。画像付きは伸びが違う。
- 節入り日は専用の投稿にする（[G30](30-solar-term-alerts.md)）。
  「今日から月柱が変わる」は他アカウントが出せない情報で、最も反応が取れる。
- 送信失敗時のリトライと、**二重投稿の防止**を入れる。
  日付をキーにした冪等性を持たせる。同じ日に2回投稿すると信用を失う。

**運用**

- 投稿時刻は朝7〜8時。生活リズムに乗る時間に固定する。
- 自動投稿だけにしない。手動の投稿を混ぜないとアカウントが機械的になる。

## 検証

- 生成部分の単体テスト（日付を与えて内容が決まること）。
- 同日二重投稿が起きないこと。
- 節入り日に専用内容が出ること。
