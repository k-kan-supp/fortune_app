# G16 YouTube 読み解き

親: [集客戦略](../../growth.md) 視点16 ／ 関連: [G15](15-tiktok-shorts.md) [G19](19-influencer-program.md)

## ねらい

[G15](15-tiktok-shorts.md) が認知なら、こちらは**信頼**。
10〜20分かけて1つの命式を読み解く動画は視聴者との関係が深く、
アプリの有料鑑定（[M12](../monetization/12-ten-gods-practical.md) 等）への転換率が高い。
検索流入もある（YouTube 内検索 + Google の動画枠）ので、
[G05](05-sexagenary-pages.md) の記事とセットで作ると相乗する。

## 開発側が用意するもの

- **画面共有に耐える表示**。動画で長時間映されるので、
  `MeishikiTable.tsx` と `AnalysisCharts.tsx` が拡大表示で崩れないこと。
  文字サイズを上げた表示モードがあると撮影が楽になる。
- 命式を URL で共有できるようにする（[G12](12-dynamic-ogp.md) のトークン方式）。
  概要欄に「この動画で扱った命式」を貼れると、視聴者が同じ画面を開ける。
  **これが動画からアプリへの最短導線**で、この指示書の実装上の核。
- 共有された命式は閲覧専用にし、閲覧者が自分の命式と比較できる導線を置く。
- 動画からの流入に専用パラメータを付け、[G34](34-analytics-foundation.md) で追う。

## 注意

- 有名人の命式を扱う場合、生年月日が公表情報であることを確認する。
  非公表の情報を推測で扱わない。
- 視聴者の命式を扱う場合は本人の明示的な許可を得る。

## 検証

- 共有 URL から命式が開けること（ログイン不要）。
- 共有 URL から生年月日が逆算できないこと。
- 拡大表示でレイアウトが崩れないこと。
