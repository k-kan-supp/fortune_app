# G36 リスティング広告

親: [集客戦略](../../growth.md) 視点36 ／ 関連: [G38](38-cpa-guardrail.md) [G01](01-seo-free-tool.md)

## ねらい

検索連動広告。[G01](01-seo-free-tool.md) の SEO が育つまでの穴埋めと、
SEO で取りにくいキーワードの補完。
**買う集客は 1–35 の数字が出てから**（[growth.md](../../growth.md) の優先順位）。
CPA 上限（[G38](38-cpa-guardrail.md)）が決まっていない状態で始めない。

## 実装

**開発側の準備**

- 広告ごとに専用のランディング先を用意できるようにする。
  トップに全部流すと、キーワードと画面の内容がずれて転換しない。
  [G05](05-sexagenary-pages.md)・[G06](06-ten-gods-pages.md) の記事ページを
  広告の受け皿として使えるようにする。
- **流入元パラメータの保持**が実装の要点。
  広告クリック → ランディング → 入力 → 結果 → 購入 まで、
  パラメータが最後まで残ること。途中の画面遷移で消えると CPA が計算できない。
  `hooks/` の1か所で保持し、[G34](34-analytics-foundation.md) の全イベントに載せる。
- 購入イベントを広告プラットフォームに返す（コンバージョン計測）。
  **返す情報を最小限にする**。ユーザーの識別子や購入内容の詳細を渡さない。

**運用側**

- 指名キーワードから始める。競合の少ない「四柱推命 無料 命式」等。
- 除外キーワードを設定する。「四柱推命 とは」のような情報収集の意図は転換しない。

## 検証

- パラメータが購入まで保持されること（全遷移経路で確認）。
- コンバージョンが二重計上されないこと。
- 広告先ページが実在すること（リンク切れの検出）。
