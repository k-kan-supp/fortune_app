# G05 干支60通りの記事

親: [集客戦略](../../growth.md) 視点5 ／ 関連: [G06](06-ten-gods-pages.md) [G03](03-glossary-pages.md)

## ねらい

日柱の干支60種それぞれに解説ページを作る。
「甲子 性格」「壬午 日柱」は検索需要があり、かつ**60ページで打ち止め**なので
[G04](04-birthdate-pages.md) のような薄いページ量産のリスクが無い。
1ページあたり1,500字以上の実質的な内容が書ける規模で、費用対効果が最も高い。

## 実装

**コンテンツ**

- 60ページ分の原稿が要る。これは開発ではなく執筆作業で、
  **ここを軽く見積もらない**。1ページ1,500字 × 60 = 90,000字。
- 自動生成した文章で埋めない。既存の `narrative.py` の出力を並べただけのページは
  内容が薄く、検索評価も読者の満足度も得られない。
- 構成を統一する: 性格の傾向 / 向く働き方 / 対人 / 相性の良い干支 / 有名人。

**実装**

- 原稿は `docs/content/pillars/{干支}.md` に置き、ビルド時に取り込む。
  DB に入れない。文章はバージョン管理されているべき。
- ルートは `/pillar/{干支ローマ字}`。日本語 URL にしない。
- 「相性の良い干支」から他の59ページへ内部リンクを張る（[G07](07-internal-linking.md)）。
  60ページが相互に繋がった塊になる。
- 各ページから「自分の日柱を調べる」でアプリへ。

## 検証

- 60ファイルが全て存在すること（欠けの検出テスト）。
- 各ファイルが文字数の下限を満たすこと。
- 内部リンクが全て有効な干支を指すこと。
- `constants.py` の干支リストとページの一覧が一致すること。
