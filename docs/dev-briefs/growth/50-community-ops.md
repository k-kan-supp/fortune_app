# G50 コミュニティ運営

親: [集客戦略](../../growth.md) 視点50 ／ 関連: [M42](../monetization/42-community-subscription.md) [G19](19-influencer-program.md)

## ねらい

**口コミの源を自前で持つ**。広告は止めれば流入が止まるが、
コミュニティは残る。四柱推命は学習コストの高い体系なので、
学び合う場への需要が実際にある。ここから将来の
インフルエンサー（[G19](19-influencer-program.md)）と
出店者（[M39](../monetization/39-reader-marketplace.md)）が育つ。
G シリーズで最も時間がかかり、最も効果が長続きする1本。

## 実装

**開発側の役割は小さい**。これは運営の仕事で、開発が用意するのは:

- 場は既存サービス（Discord 等）に置く。自前の掲示板を作らない
  （[M42](../monetization/42-community-subscription.md) と同じ）。
  掲示板を自作すると、モデレーション機能の開発が延々と続く。
- 会員資格の同期は [M42](../monetization/42-community-subscription.md) が実装する。
  ここでは作らない。この指示書は**場の中身**（学習リソース・共有導線・運営方針）を持つ。
- 命式を共有できる URL（[G16](16-youtube-readings.md) のトークン方式）。
  コミュニティ内で「この命式どう読みますか」という会話が成立する。**これが場の中心になる**。
- 用語辞典（[G03](03-glossary-pages.md)）を学習リソースとして整える。

**運営側で先に決めること**

- モデレーションの方針。占いの解釈は流派差で対立が起きやすい。
  「流派の違いは優劣ではない」を明文化しておく。
- 個人の悩み相談が集まる場になる。医療・法律・金銭に関する助言の扱いを決める
  （[M17](../monetization/17-wealth-reading.md) [M18](../monetization/18-health-reading.md) と同じ規律）。
- 運営に割ける時間を先に決める。片手間では場が荒れる。

## 検証

- 共有 URL から生年月日が読み取れないこと。
- 会員資格の同期（解約時の剥奪）が動くこと。

- [ ] 命式の共有 URL がある
- [ ] モデレーション方針が文書化されている
