# G14 Instagram 命式カード

親: [集客戦略](../../growth.md) 視点14 ／ 関連: [G11](11-share-card-image.md) [G13](13-x-daily-bot.md)

## ねらい

占いは Instagram との相性が良いジャンルで、保存（ブックマーク）されやすい。
[G13](13-x-daily-bot.md) と違い、**流れて消えない**のでストック型の資産になる。
干支60種・十神10種（[G05](05-sexagenary-pages.md) [G06](06-ten-gods-pages.md)）の
記事は、そのままカルーセル投稿の素材になる。

## 実装

**backend**

- [G11](11-share-card-image.md) の `share/card.py` に正方形（1080×1080）テンプレートを追加。
  複数枚のカルーセル用に、連番で生成できるようにする。
- Instagram は API 経由の自動投稿に制約が多い。**まず手動運用**で反応を見る。
  自動化は投稿本数が運用の負担になってからで良い。
  この指示書の実装範囲は「投稿素材の生成」までとする。
- テキストはフォントサイズを大きく取る。小さい文字はフィードで読まれない。
  1枚あたりの情報量を欲張らない。
- ブランドの一貫性を持たせる。配色・レイアウトを固定したテンプレートにし、
  投稿ごとに変えない。

**frontend**

- ユーザー自身が自分の命式カードを正方形で保存できるようにする。
  UGC（[G18](18-ugc-funnel.md)）の素材になる。

## 検証

- 生成画像が Instagram の推奨解像度・アスペクト比に合っていること。
- 文字が小さすぎないこと（実機のフィード表示で確認）。
- カルーセル用の連番生成が動くこと。
