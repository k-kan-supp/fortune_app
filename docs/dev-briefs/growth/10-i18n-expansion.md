# G10 多言語展開

親: [集客戦略](../../growth.md) 視点10 ／ 関連: [G01](01-seo-free-tool.md) [G03](03-glossary-pages.md)

## ねらい

既に ja/en が同型で入っている（`frontend/src/i18n/messages/`）ので、
言語追加の構造的コストが低い。四柱推命は東アジア圏で通用する体系で、
**韓国（사주）と台湾・香港（八字）には大きな需要がある**。
英語圏は競合が薄く、日本語より上位を取りやすい。

## 実装

- 追加順は 1) 繁体字中国語 2) 韓国語。理由は市場規模と用語の対応の付けやすさ。
  簡体字圏は規制の問題があるので後回し。
- `i18n/messages/` に `zh-TW.ts` / `ko.ts` を追加。
  **ja/en と完全に同じキー構造**にする（CLAUDE.md の規約をそのまま拡張）。
  キーの欠落をテストで検出する仕組みを、言語追加の前に入れる。
  2言語なら目視で足りるが、4言語では無理。
- サーバ発の文言は `backend/app/core/i18n.py` の `MESSAGES` も同時に追加する。
- **用語は現地の呼称を使う**。日本語の「四柱推命」を音訳しない。
  台湾では八字、韓国では사주。ここを間違えると検索で全く引っかからない。
- URL 構造を先に決める。`/zh-tw/...` のパス方式にし、
  後から変えられない前提で設計する。`hreflang` を全ページに入れる。

## 検証

- 全言語でキー構造が一致すること（自動テスト。これが本指示書の核）。
- `hreflang` が相互に正しく張られていること。
- 各言語で命式の用語が現地表記になっていること。
