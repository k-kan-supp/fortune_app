# G49 誕生日クーポン

親: [集客戦略](../../growth.md) 視点49 ／ 関連: [M50](../monetization/50-gifting.md) [G26](26-push-timing.md)

## ねらい

**生年月日を必ず持っている**プロダクトなので、誕生日施策の実装コストがゼロに近い。
季節キャンペーン（[G47](47-new-year-season.md) [G48](48-risshun-campaign.md)）が
年に数回の山なのに対し、誕生日は**年間を通じて平準化された接点**を作る。
四柱推命では誕生日に「新しい年運が始まる」意味付けもできる。

## 実装

**backend**

- `app/services/notification/` に誕生日の配信を追加。
  対象抽出は月日でのクエリ。**年齢を表示しない**設定を用意する。
  年齢に触れられたくない人は一定数いる。既定では触れない。
- 内容は「あなたの新しい1年の運勢」。
  [M13](../monetization/13-luck-cycles.md) の年運を材料にする。
  誕生日を起点にした1年（誕生日〜次の誕生日）で読むと、
  一般的な年運（立春起点）とは別の商品になる。**どちらの起点かを明示する**。
- クーポンは [M50](../monetization/50-gifting.md) のギフトコード基盤を流用する。
  新しいクーポン基盤を作らない。
- 誕生日通知をオフにできるようにする（[G26](26-push-timing.md) の種類別オフ）。

**frontend**

- 誕生日当日にアプリを開いたときの表示を用意する。
  通知を切っている人にも届く。

## 検証

- 2月29日生まれの扱い（平年にいつ配信するか）を決めてテストする。
- 通知オフが効くこと。
- クーポンの有効期限が正しいこと。
- 年齢非表示の設定が効くこと。
