# G19 占い師インフルエンサー

親: [集客戦略](../../growth.md) 視点19 ／ 関連: [M39](../monetization/39-reader-marketplace.md) [G16](16-youtube-readings.md)

## ねらい

既にフォロワーを持つ占い師に使ってもらう。
一般的なインフルエンサー施策と違い、**この人たちは将来の出店者**
（[M39](../monetization/39-reader-marketplace.md)）でもある。
一度きりの宣伝依頼ではなく、ツールとして常用してもらう関係を作る方が長期的に効く。

## 実装

**開発側が用意するもの**

- **プロ向けの機能**が要る。一般ユーザー向けの UI のままでは仕事に使えない:
  - 複数の顧客の命式を管理する（[M23](../monetization/23-reading-history.md) の履歴の上位版）
  - 命式を並べて比較する
  - 鑑定メモを命式に紐づけて残す
  - 印刷・PDF（[M24](../monetization/24-pdf-export.md)）で顧客に渡せる
- **顧客の個人データを預かることになる**点を明示的に設計する。
  占い師のアカウントに他人の生年月日が大量に溜まる。
  保存件数の上限、退会時の削除、エクスポート手段を用意する。
- 紹介コード（[G20](20-referral-reward.md) の仕組みを流用）で成果を追う。

**やらないこと**

- 単発の宣伝報酬。効果が測りにくく、関係も続かない。

## 検証

- プロ向け機能で他人のデータが混ざらないこと。
- 退会時に預かったデータが確実に消えること。
- 紹介コード経由の流入が計測できること。

## 完了条件

- [ ] プロ向けの命式管理機能がある
- [ ] 預かるデータの削除経路がある
- [ ] 紹介成果が計測できる
