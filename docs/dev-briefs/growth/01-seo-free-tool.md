# G01 無料ツールとしての SEO

親: [集客戦略](../../growth.md) 視点1 ／ 関連: [M01](../monetization/01-free-paid-line.md) [G02](02-tool-landing.md)

## ねらい

「四柱推命 無料」「命式 計算」は検索需要が大きく、かつ**このアプリが既に持っている機能**そのもの。
広告費ゼロで最も大きな流入源になり得る。前提は [M01](../monetization/01-free-paid-line.md) ──
命式を無料で出し切ること。ここを囲うと以降 G02〜G07 が全部成立しない。

## 実装

**最大の障壁**: 現状は Vite の SPA で、検索エンジンに中身が見えない。
これを解決しないと他の SEO 施策を何本積んでも効かない。ここが本指示書の本体。

- 判断が要る。3案:
  1. Vite の SSG（`vite-plugin-ssr` 等）で静的生成する
  2. 公開ページだけを別の静的サイトとして切り出す
  3. FastAPI 側でサーバサイドレンダリングを返す
  1 を推す。既存の React コンポーネントを再利用でき、
  アプリ本体（要ログイン部分）は SPA のまま残せる。
- 対象は入力フォームと結果表示までの導線。マッチング機能は対象外（ログインが要る）。
- `<title>` / `<meta description>` をページごとに設定する。SPA の共通タイトルのままにしない。

**backend**

- 静的生成時に `/api/fortune` を呼ぶことになるので、
  ビルド時に叩ける形（認証不要の公開エンドポイント）が要る。既に無料なら追加作業は無い。

## 検証

- 生成された HTML に命式の中身が含まれること（JS 無効で確認）。
- 主要ページの `title` / `description` が固有であること。
- ビルド時間が現実的な範囲に収まること（[G04](04-birthdate-pages.md) で大量生成する前提）。
