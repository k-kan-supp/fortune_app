# G37 Meta 広告

親: [集客戦略](../../growth.md) 視点37 ／ 関連: [G36](36-search-ads.md) [G11](11-share-card-image.md)

## ねらい

検索広告（[G36](36-search-ads.md)）が「探している人」を捕まえるのに対し、
こちらは**探していない人**に見つけてもらう。占いは
「言われてみれば気になる」ジャンルなので相性が良い。
勝負はクリエイティブで、**同じ予算でも素材次第で数倍変わる**。
開発側の役割は素材を量産できる状態を作ること。

## 実装

**開発側**

- [G11](11-share-card-image.md) の画像生成基盤を広告素材にも使う。
  命式カードのバリエーション（干支別・十神別）を機械的に量産できると、
  素材の入れ替えが速く回る。これが本指示書の実装上の核。
- 動画素材が要る場合は [G15](15-tiktok-shorts.md) の縦画面対応が前提。
- **Meta ピクセルの導入は慎重に**。行動データを外部に渡すことになる。
  - 送るイベントを限定する（ページビューと購入のみ）。
  - 命式の内容・生年月日を渡さない（[G34](34-analytics-foundation.md) と同じ規律）。
  - 同意を得たユーザーのみに適用する。同意管理と連動させる。
- マッチング機能を訴求する広告は、審査で落ちやすい。
  占い機能を主訴求にした方が通りやすく、転換も良い。

## 検証

- ピクセルに命式・生年月日が送られないこと。
- 同意していないユーザーでピクセルが発火しないこと。
- 広告素材の生成が自動化されていること。
