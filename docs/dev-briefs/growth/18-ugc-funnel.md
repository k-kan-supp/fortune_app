# G18 UGC 導線

親: [集客戦略](../../growth.md) 視点18 ／ 関連: [G11](11-share-card-image.md) [G21](21-partner-birthdate-invite.md)

## ねらい

ユーザー自身に結果を投稿してもらう。広告と違い**投稿は消えずに積み上がる**。
占いの結果は「当たってる」「当たってない」の両方が投稿の動機になるので、
好意的な結果だけを狙う必要が無い。むしろ**意外性のある結果**の方が投稿される。

## 実装

**frontend**

- 投稿しやすいのは「一言で言えること」。
  「あなたは〇〇タイプ」のような短いラベルを結果画面に1つ置く。
  レーダー10枚は投稿されない。**要約が投稿される**。
- 共有ボタンは結果表示の直後に置く。読み終わった後では熱が下がっている。
- 共有文のテンプレートを用意する。ハッシュタグを含める。
  ただし過剰な定型文は避ける。「アプリに書かされた」感が出ると投稿されない。
- 画像（[G11](11-share-card-image.md)）を必ず添付する。

**backend**

- 共有経由の流入を計測する。どの共有経路（X / LINE / 画像保存）が
  実際に新規ユーザーを連れてきたかを [G34](34-analytics-foundation.md) で分解する。
  共有ボタンのクリック数ではなく、**そこから来た新規数**を見る。

## 検証

- 共有 URL からの流入が新規ユーザーとして計測されること。
- 共有された URL から投稿者の生年月日が読み取れないこと
  （[G12](12-dynamic-ogp.md) と同じ規律）。
- 共有経路別に分解できること。
