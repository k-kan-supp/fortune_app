# G28 ホーム画面ウィジェット

親: [集客戦略](../../growth.md) 視点28 ／ 関連: [M02](../monetization/02-subscription-daily.md) [G26](26-push-timing.md)

## ねらい

ホーム画面に今日の運勢を常時表示する。
通知（[G26](26-push-timing.md)）は消されるが、ウィジェットは**置かれ続ける**。
アプリを開かなくても目に入るので、忘れられにくい。
日次の運勢という毎日変わるコンテンツを持っているアプリでこそ意味がある。

## 実装

**前提の判断**

- ウィジェットはネイティブアプリの機能。現状は Web（Vite + React）なので、
  **アプリ化が前提になる**。この指示書は「アプリを出すか」の判断とセット。
  Web のままなら [G26](26-push-timing.md) と [G17](17-line-official.md) で代替する。
- PWA でもホーム画面追加はできるが、ウィジェットは限定的。過度な期待をしない。

**アプリ化する場合**

- ウィジェット用の軽量エンドポイントを作る。
  `GET /api/fortune/daily/summary` として、四領域の記号と一言だけを返す。
  フル応答をウィジェットで受けると更新が重い。
- 更新頻度を抑える。日付が変わる時と、明示的な更新時のみ。
  ウィジェットの頻繁な更新はバッテリー消費で嫌われる。
- 未ログイン・未設定時の表示を用意する。空のウィジェットは削除される。

## 検証

- 軽量エンドポイントの応答サイズと時間。
- 日付変更時に内容が切り替わること。
- 未設定時に案内が表示されること。
