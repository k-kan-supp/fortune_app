# G41 レビュー依頼

親: [集客戦略](../../growth.md) 視点41 ／ 関連: [G40](40-aso.md) [G27](27-streaks.md)

## ねらい

ストアの評価は [G40](40-aso.md) の順位とインストール率の両方に効く。
**依頼するタイミングが全て**。適当な時に出すと低評価を集めることになり、
やらない方がマシな結果になる。満足度が最も高い瞬間を特定して、そこだけで出す。

## 実装

**タイミングの設計**（この指示書の本体）

- 出す条件を全て満たしたときのみ:
  - 3回以上アプリを開いている（初回では出さない）
  - 直前の操作が成功している（エラー直後に出さない）
  - 満足度が高いと推定できる行動の直後 ── 具体的には
    **日次の運勢を7日連続で見た直後**（[G27](27-streaks.md)）か、
    **相性詳細を読み終えた直後**（[M15](../monetization/15-pair-compatibility-detail.md)）
  - 過去に依頼してから90日以上経過している
- **課金導線の直後に出さない**。金を払わせた直後の依頼は反感を買う。
- 一度断った人には出さない。

**実装**

- 条件判定を `frontend/src/hooks/useReviewPrompt.ts` に集約する。
  各画面に条件を書き散らさない。
- 依頼の表示・結果を [G34](34-analytics-foundation.md) に記録し、
  条件ごとの評価分布を後から見られるようにする。

## 検証

- 全条件を満たさない限り表示されないこと（条件ごとの単体テスト）。
- 90日の間隔が守られること。
- エラー直後に表示されないこと。
