# G40 ASO

親: [集客戦略](../../growth.md) 視点40 ／ 関連: [G41](41-review-prompt.md) [G28](28-home-widget.md)

## ねらい

アプリストア内の検索最適化。「四柱推命」でストア検索する人は
**購入意欲が Web 検索より高い**。ただしこれはアプリを出すことが前提で、
アプリ化そのものが大きな判断（[G28](28-home-widget.md) と同じ論点）。
Web で [G01](01-seo-free-tool.md) が回っているなら、急がなくて良い。

## 実装

**アプリ化の方針**

- 既存の React 資産を活かすなら、Web View 主体のハイブリッドか
  React Native への移植。**ストアの審査基準では、Web をラップしただけのアプリは
  リジェクトされ得る**。通知・ウィジェット（[G28](28-home-widget.md)）など、
  ネイティブでしかできない価値を最低1つ持たせる。

**ASO の実装項目**

- アプリ名に主要キーワードを含める（「四柱推命」を名前に入れる）。
- スクリーンショットの1枚目で命式画面を見せる。文字での説明を並べない。
- 説明文の冒頭3行が検索結果に出る。ここに何ができるかを書く。
- **課金がある場合、審査で決済方式の指摘を受ける**。
  デジタルコンテンツの販売はストア内課金が必要になる。手数料を含めた価格設計
  （[M26](../monetization/26-three-tier-pricing.md)）を、アプリ化の判断と同時に見直す。
- 多言語（[G10](10-i18n-expansion.md)）のストア掲載を用意する。

## 検証

- ストアの審査ガイドラインに対する自己点検を実施し、記録する。
- 課金の方式が審査要件を満たすこと。
- 主要キーワードでストア検索して自アプリが出ること。

## 完了条件

- [ ] ネイティブ固有の価値が1つ以上ある
- [ ] 課金方式が審査要件を満たす
- [ ] ストア掲載物が用意されている
- [ ] `check.sh` 緑
