# G11 結果カード画像

親: [集客戦略](../../growth.md) 視点11 ／ 関連: [G12](12-dynamic-ogp.md) [M22](../monetization/22-radar-interpretation.md)

## ねらい

命式とレーダーチャートを1枚の画像にして、SNS に貼れるようにする。
**チャートが全て同じ形（`key` / `max_value` / `axes`）に揃っている**
（[architecture.md](../../architecture.md)）ので、1つのレンダラで10枚とも賄える。
テキストのシェアより画像の方が圧倒的に拡散する。

## 実装

**backend**

- `app/services/share/card.py` を新設。SVG を組み立てて PNG に変換する。
  ヘッドレスブラウザは使わない（重い・不安定）。SVG からの直接変換にする。
- [M24](../monetization/24-pdf-export.md) の PDF 生成と**同じ描画コード**を使う。
  PDF・画像・画面の3か所で図がずれると信用を失う。共通の描画モジュールにする。
- 日本語フォントの埋め込みが必要（[M24](../monetization/24-pdf-export.md) と同じライセンス確認）。
- キャッシュする。同じ命式のカードは何度でも同じものになる。
  `(subject_hash, card_type, lang)` をキーにする。
- **画像に個人を特定する情報を入れない**。名前は入れず、生年月日も入れない。
  命式（干支）だけにする。SNS に投稿されるものなので、
  そこから生年月日が逆算できる状態にしない。

**frontend**

- 結果画面に「画像を保存」。共有 API が使える環境では直接共有に繋ぐ。
- 有料の解釈文は画像に含めない。

## 検証

- 画面・PDF・画像の3つで同じ図になること。
- 画像に生年月日・氏名が含まれないこと。
- 日本語が欠落しないこと。
- 全10種のチャートで生成できること。
