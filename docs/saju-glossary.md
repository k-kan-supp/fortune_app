# 四柱推命 用語辞典

このリポジトリのコードに出てくる四柱推命の用語を引くための辞書。
定数名・関数名がそのまま漢字の専門用語になっているため、
`constants.py` を読む前にここで意味と実装の対応を確認できるようにしてある。

**利用者向けの解説とは別物**であることに注意。
画面に出す平易な説明文は `frontend/src/i18n/messages/{ja,en}.ts` の `glossary` に置いてあり、
そちらは占いを知らない人が読む前提で書かれている。この文書は実装を読む人向けで、
「なぜその計算になるのか」を説明する。

実装は `backend/app/services/saju/` に集約されている。

| モジュール | 担当 |
| --- | --- |
| `constants.py` | 干支・五行・十神などの基礎テーブル |
| `pillars.py` | 生年月日時 → 四柱・日主 |
| `ten_gods.py` | 十神の判定 |
| `twelve_stages.py` | 十二運星の判定 |
| `analysis.py` | 命式 → 各種バランス指標（レーダーチャート） |
| `compatibility.py` | 二人の命式 → 相性 |

## 1. 命式の骨組み

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 四柱推命 | しちゅうすいめい | 生年月日時を四つの干支に置き換えて読む占術。本アプリの土台 | — |
| 命式 | めいしき | 四柱を並べた表そのもの。占断の入力データにあたる | `FortuneResponse` |
| 四柱 | しちゅう | 年柱・月柱・日柱・時柱の四本 | `four_pillars()` |
| 柱 | ちゅう | 天干と地支を上下に組んだ一本 | `Pillar` |
| 干支 | かんし / えと | 天干と地支の組。60通りで一巡する（六十干支） | `Pillar.stem` + `.branch` |

### 各柱が受け持つ領域

古典では柱ごとに人生の場面を割り当てる。`glossary.pillar` の説明文がこれに対応する。

| 柱 | 表すもの |
| --- | --- |
| 年柱 | 幼少期・家系・第一印象 |
| 月柱 | 仕事や社会での立ち位置・親との関係（命式の中心） |
| 日柱 | 自分自身と配偶者（命式の要） |
| 時柱 | 晩年・子ども・内に秘めた願い |

## 2. 天干と地支

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 天干 / 十干 | てんかん / じっかん | 甲乙丙丁戊己庚辛壬癸 の10文字。柱の上段 | `HEAVENLY_STEMS` |
| 地支 / 十二支 | ちし / じゅうにし | 子丑寅卯辰巳午未申酉戌亥 の12文字。柱の下段 | `EARTHLY_BRANCHES` |
| 日主 / 日干 | にっしゅ / にっかん | **日柱の天干**。命式の主人公で、十神も十二運星もすべてここを基準に決まる | `day_master` |
| 蔵干 | ぞうかん | 地支の内側に隠れている天干。地支は複数の気を含むという考え方 | `BRANCH_HIDDEN_STEMS` |
| 本気 / 中気 / 余気 | ほんき / ちゅうき / よき | 蔵干の強さの序列。先頭が本気で最も強い | `HIDDEN_STEM_WEIGHTS` |
| 月令 | げつれい | 月支が司る季節。命式全体の強弱を左右する | `MONTH_HIDDEN_STEM_WEIGHTS`, `SEASON_ELEMENT` |

### 気の重みづけ

五行や十神の構成比を出すとき、干は等価には数えない。

| 対象 | 重み | 理由 |
| --- | --- | --- |
| 天干 | 1.0 | 表に出ている気 |
| 蔵干（通常の柱） | 1.0 / 0.5 / 0.3 | 本気・中気・余気の順に弱める |
| 蔵干（月柱） | 1.5 / 0.8 / 0.5 | 月支は季節を司り影響が大きいため重く見る |

重みはすべて 0.1 刻みに揃えてあり、合計を小数第1位に丸めても内訳と総和がずれない。
実装は `analysis.py` の `_weighted_stems()`。

## 3. 陰陽五行

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 五行 | ごぎょう | 木・火・土・金・水。すべての気をこの5種に分類する | `FIVE_ELEMENTS` |
| 陰陽 | いんよう | 干の性質を陽（＋）と陰（−）に分ける。甲丙戊庚壬が陽、乙丁己辛癸が陰 | `STEM_YANG` |
| 相生 | そうしょう | 一方が他方を**生む**（強める）関係 | `GENERATES` |
| 相剋 | そうこく | 一方が他方を**剋す**（抑える）関係 | `CONTROLS` |

```
相生（生む）    木 → 火 → 土 → 金 → 水 → 木
相剋（剋す）    木 → 土 → 水 → 火 → 金 → 木
```

十神・相性判定はどちらもこの2つの循環から導かれるので、
この2表が命式計算全体の根になっている。

## 4. 十神（通変星）

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 十神 / 通変星 | じっしん / つうへんせい | **日主から見た**他の干の関係を10種に分類したもの | `TEN_GODS`, `ten_god()` |

五行の関係（同じ／生む／剋す）と陰陽の異同の掛け合わせで決まる。

| 日主との五行関係 | 陰陽が同じ | 陰陽が違う | グループ |
| --- | --- | --- | --- |
| 同じ五行 | 比肩（ひけん） | 劫財（ごうざい） | 比劫 |
| 日主が**生む** | 食神（しょくじん） | 傷官（しょうかん） | 食傷 |
| 日主が**剋す** | 偏財（へんざい） | 正財（せいざい） | 財星 |
| 日主を**剋す** | 偏官（へんかん） | 正官（せいかん） | 官殺 |
| 日主を**生む** | 偏印（へんいん） | 印綬（いんじゅ） | 印星 |

> 偏官は**七殺（しちさつ）**とも呼ばれる。英語表記の `Seven Killings` はこちらに由来する。

### 十神グループ

十神は2つずつ束ねて5グループで扱うことが多い。
性格特性・分野別運勢・相性の「考え方」は、すべてこのグループの構成比から算出している。

| グループ | よみ | 含む十神 | 担うもの |
| --- | --- | --- | --- |
| 比劫 | ひごう | 比肩・劫財 | 自我。自分の強さと仲間との関係 |
| 食傷 | しょくしょう | 食神・傷官 | 表現・発信・生み出す力 |
| 財星 | ざいせい | 偏財・正財 | お金・現実的な成果・人との交わり |
| 官殺 | かんさつ | 偏官・正官 | 責任・規律・社会での役割 |
| 印星 | いんせい | 偏印・印綬 | 学び・支え・受け取る力 |

実装は `TEN_GOD_GROUPS` / `TEN_GOD_GROUP`（十神→グループの対応表）。

## 5. 十二運星

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 十二運星 | じゅうにうんせい | 日主が各地支で持つ勢いを、人の一生になぞらえて12段階で表す | `TWELVE_STAGES`, `twelve_stage()` |

長生（誕生）から絶（消滅）を経て胎・養（再生）へ戻る循環。

| 段階 | よみ | 勢い | 段階 | よみ | 勢い |
| --- | --- | --- | --- | --- | --- |
| 長生 | ちょうせい | 9 | 病 | びょう | 4 |
| 沐浴 | もくよく | 7 | 死 | し | 2 |
| 冠帯 | かんたい | 10 | 墓 | ぼ | 5 |
| 建禄 | けんろく | 11 | 絶 | ぜつ | 1 |
| 帝旺 | ていおう | 12 | 胎 | たい | 3 |
| 衰 | すい | 8 | 養 | よう | 6 |

「勢い」は柱ごとの強さを比較するための点数（`TWELVE_STAGE_ENERGY`）。
帝旺が最強・絶が最弱で、並び順とは一致しない点に注意。

### 並べ方

日干ごとに「長生」にあたる地支が決まっており（`STAGE_ORIGIN_BRANCH`）、
そこを起点に**陽干は十二支を順行、陰干は逆行**して残り11段階を並べる。

## 6. 旺相休囚死

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 旺相休囚死 | おうそうきゅうしゅうし | 月支の季節から見た、五行それぞれの勢い | `SEASONAL_STATES` |

| 状態 | 定義 |
| --- | --- |
| 旺 | その季節を司る五行（当令）。最も勢いがある |
| 相 | 旺が生む五行。次に控える伸び盛り |
| 休 | 旺を生み終えた五行。役目を終えて休む |
| 囚 | 旺を剋そうとして力を出せない五行 |
| 死 | 旺に剋される五行。最も勢いを失う |

季節の割り当ては `SEASON_ELEMENT`。辰・未・戌・丑は**土用**として土が旺じる。

> **命名の衝突**：「死」は十二運星にもある。意味は別物（十二運星＝動きが止まる時期、
> 旺相休囚死＝旺に剋された状態）なので、フロントは用語の種別（`ns`）で解説文を出し分ける。
> `frontend/src/features/fortune/glossary.ts` の `CHART_TERM_NS` と、
> `terms.ts` の `AXIS_EN_BY_NS`（`死` → `Dormant`）を参照。

## 7. 地支どうしの関係

相性判定（`compatibility.py`）で日支どうしを突き合わせるときに使う。

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 六合 | りくごう | 引き合って結びつく2支の組。最も縁が強い | `SIX_HARMONY` |
| 三合 | さんごう | 同じ五行の**局**をつくる3支の組 | `THREE_HARMONY` |
| 冲 | ちゅう | 正面から向き合ってぶつかる組（対沖） | `CLASH` |
| 害 | がい | 六合を邪魔する組。冲ほど強くないが噛み合いにくい | `HARM` |
| 局 | きょく | 三合が生み出す五行のまとまり | — |

```
六合   子丑 / 寅亥 / 卯戌 / 辰酉 / 巳申 / 午未
三合   申子辰（水局）/ 亥卯未（木局）/ 寅午戌（火局）/ 巳酉丑（金局）
冲     子午 / 丑未 / 寅申 / 卯酉 / 辰戌 / 巳亥
害     子未 / 丑午 / 寅巳 / 卯辰 / 申亥 / 酉戌
```

> 実装上の注意：二人の日支を見るだけなので、三合は**2支が揃った時点で成立**として扱う。
> ただし**同支は三合ではなく比和**（`same`）とする。すべての地支がいずれかの三合に属する以上、
> 同支の判定を三合より先に置かないと、同じ支どうしがすべて三合として拾われてしまう。
> `_branch_relation()` の判定順がそのまま仕様になっている。

## 8. 暦まわり

| 用語 | よみ | 意味 | 実装 |
| --- | --- | --- | --- |
| 節入り | せついり | 干支が切り替わる境目。月の変わり目は1日ではなく節気で決まる | sxtwl に委譲 |
| 立春 | りっしゅん | 年柱が切り替わる節。2月4日前後で、元日ではない | sxtwl に委譲 |
| 五鼠遁 | ごそとん | 日干から時柱の天干を導く規則 | `pillars.py` |

干支と節入りの天文計算は **sxtwl（寿星天文暦）** に委譲しており、自前では暦を持たない。

時柱だけは sxtwl が返さないため自前で組み立てる。

- **時支**：2時間刻み。`((hour + 1) // 2) % 12` で、23:00〜00:59 が子。
- **時干**：五鼠遁。`(day_stem_idx % 5 * 2 + hour_branch_idx) % 10`

| 用語 | よみ | 意味 |
| --- | --- | --- |
| 男命 / 女命 | なんめい / じょめい | 男性の命式／女性の命式 |
| 妻星 / 夫星 | さいせい / ふせい | 配偶者を表す星。男命は財星、女命は官星 |

## 既知の割り切り

占術としての厳密さより実装の単純さを取っている箇所。仕様変更時の判断材料として残す。

- **真太陽時の補正をしていない**。出生地の経度による時差を見ないため、
  時柱が本来の隣の刻になる場合がある。入力に出生地を持たせていないことによる。
- **`FortuneRequest.minute` は受け取るが使っていない**。時支は2時間刻みなので、
  分の情報は現状どこにも効かない（真太陽時を導入するなら必要になる）。
- **`is_male` の説明が実態とずれている**。スキーマの説明文は「大運の順逆に使用」とあるが、
  大運は未実装で、実際の用途は恋愛運の主星の切り替えのみ。
- **十二運星は日主のみから見ている**。柱ごとの干を基準に見る流派もあるが採用していない。
